I have created a website in which: The application operates as a serverless, client-side computer vision engine which captures natural light waves through the HTML5 MediaDevices API, makes mobile operating systems start from the  camera a directly onto a zero-latency viewfinder. When a frame is captured, the system paints the active viewport data onto an off-screen HTML5 canvas matrix, sampling the exact center coordinates to extract raw, unsigned 8-bit integers representing the precise Red, Green, and Blue channels. Because human eyes perceive color non-linearly with a heightened sensitivity to red and green entities, the engine passes these RGB values through a specialized weighted perceptual distance algorithm executing a greedy optimization loop across a hardcoded data dictionary to isolate the absolute lowest mathematical delta. Once the closest factory profile is locked, the engine parses its datavincluding family prefixes and alphanumeric tracking boundaries to dynamically generate adjacent catalog shade badges directly in the DOM, while concurrently rendering an environmental lighting warning to provide users an instant manual index fallback if background shadows distort the initial digital calculation.
